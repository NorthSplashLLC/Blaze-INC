# B.L.A.Z.E. Incorporated LLC Website

A complete responsive React/Vite website for B.L.A.Z.E. Incorporated LLC.

## Included pages

- Home
- About
- Programs
- Impact
- Get Involved
- Contact

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push this folder to GitHub.
2. Import the repository into Vercel.
3. Vercel should detect Vite automatically.
4. Build command: `npm run build`
5. Output directory: `dist`

A `vercel.json` file is already included so the React Router pages work when refreshed directly.

## Main editable content

- Organization/program text: `src/content.js`
- Main page sections: `src/pages/`
- Header/footer/contact links: `src/components/Layout.jsx`
- Styling/colors: `src/styles.css`
- Logo: `public/assets/blaze-logo.jpeg`
